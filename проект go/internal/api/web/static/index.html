    Middleware не пускает к заявкам без JWT или с поддельным токеном.

    Graceful shutdown

    Выполни в терминале и посмотри логи: сервер дожидается текущих запросов и закрывает соединения.

    docker compose stop api
docker compose logs api | tail -8
docker compose start api

    Индикатор в правом верхнем углу покажет, что api недоступен, а потом снова в строю.

    Мониторинг в реальном времени

    Графики встроены из Grafana и обновляются каждые 5 секунд. Чтобы они ожили, запусти нагрузку: docker compose --profile load up -d loadgen
